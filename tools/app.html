How this works

Each cell is 10 × 10 km in LV95. At LK25-native 2.5 m/px one cell costs roughly 10 tiles on the watch. A 500-tile cap is about 50 cells.

Plain drag still pans the map. While Ctrl or Shift is held, the cursor changes and the controls box highlights the active mode.

GitHub Actions (no local install)
            
Fork the repository, open Actions → Build routable IMG → Run workflow, paste these inputs. Download the .img from the run's artifacts (~10 min).

          
Build time on 4 cores: ~1 min for a city, ~6 min for all of Switzerland. The first run downloads the Swiss OSM extract (~650 MB).
