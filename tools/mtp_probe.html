Garmin USB probe

Connects to a Garmin device over USB straight from the browser (WebUSB + MTP) and lists the map files on it. Nothing is written, moved or deleted. Purpose: find out whether a browser-based map manager works on fēnix 9 Pro / Edge 1050.

WebUSB not available. Use Chrome, Edge, Brave or Opera on a desktop computer, over https:// or localhost. Firefox and Safari do not support WebUSB.

1 · Prepare

  • Connect the device with a data USB cable and wake it.
  • Close every program that talks to the device: Garmin Express, OpenMTP, Android File Transfer, file managers showing it.
  • Linux: unmount it in the file manager (or gio mount -u mtp://…). If access is denied, add a udev rule: SUBSYSTEM=="usb", ATTR{idVendor}=="091e", MODE="0666".
  • Windows: Windows usually claims MTP devices itself, so this probe is expected to fail there. A failure report is still useful.
