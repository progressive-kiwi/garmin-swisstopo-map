Rebuilt monthly by the build-routable-img GitHub Actions workflow from the current OpenStreetMap extract. Name and family ID of the prebuilt file are fixed (“CH routable”, 6421); a custom name needs a build kit.

Custom areas are compiled on your own machine or on GitHub Actions (mkgmap is Java; it does not run in a browser). The kit is self-contained: script, mkgmap options, your area.

Notes


Compatibility status (October 2026)
  
    
    
  • fēnix 9 Pro ships with a rewritten mapping engine (perspective view, faster pan/zoom). Garmin has not published a statement on third-party .img support under the new engine, and no public user report confirms or denies it yet. The format is the same one the fēnix 6/7/8 accept. Recommended: install a small test area first (one city, ~10 MB) before the full country.
    • 
    
  • fēnix 8 firmware listed third-party maps under the CityNavigator map layer instead of individually; firmware 11.81+ allows toggling them. Expect the same placement on fēnix 9.
    • 
    
  • Edge 1050: third-party .img in Garmin/Maps/ confirmed by users. USB is MTP only.
    • 
    
  • Raster KMZ packs on fēnix 9: not verified on the new engine. Both kinds can coexist; for the smoothest panning, keep the Custom Maps (KMZ) layer off while using the vector map.
    • 
  




Why OpenStreetMap and not swisstopo data
  
Routing needs a connected road/path graph with access, one-way and turn-restriction tags in Garmin's NOD format. mkgmap produces that from OSM directly. swisstopo's open swissTLM3D has an equivalent network, but converting it to routable Garmin format needs a full attribute mapping not yet written for this project. OSM coverage of Swiss roads and paths is near complete.




What the build contains
  
    
    
  • Routing graph (NOD/NET), address and POI index (MDR), house numbers.
    • 
    
  • Geometry simplification (reduce-point-density, merged lines) for faster drawing.
    • 
    
  • mapnik-style TYP (colour scheme close to openstreetmap.org); omit with --no-typ for Garmin default colours.
    • 
    
  • Excluded: DEM / hillshading, contour lines, hiking-route relation overlays.
